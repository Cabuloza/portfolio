# Portfolio

A personal portfolio website showcasing my web development projects, design work, and multilingual support. Built with clean HTML, CSS, and JavaScript.

## Folder Structure

```text
portfolio/
├── README.md
├── index.html
├── 404.html
├── css/
│   └── style.css
├── header/
│   ├── header.css
│   ├── header.html
│   ├── header.js
│   └── project-covers/
├── languages/
│   ├── de.json
│   ├── en.json
│   ├── fr.json
│   ├── sr.json
│   └── i18n.json
└── projects/
    ├── cisv website
    ├── expenses tracker
    ├── notepad app
    ├── personal-logo
    ├── renvou
    └── music library
├── background-donut
└── assets/
```

## Features

* **Multilingual Support:** Localized in English (`en`), German (`de`), French (`fr`), and Serbian (`sr`) via JSON configuration.
* **Modular Header:** Dedicated components for header logic, styling, and dynamic project covers.
* **Featured Projects:** A curated list of web applications and design pieces including a CISV website, expense tracker, notepad app, and more.
* **Custom Error Handling:** Styled `404.html` page for missing routes.

## Technologies Used

* **HTML5** for page structure.
* **CSS3** for styling and layouts.
* **JavaScript (ES6+)** for interactivity and internationalization (i18n).
